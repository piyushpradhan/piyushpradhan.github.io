# Privacy Policy for Shortcut to Notion Extension

**Last updated:** [15-08-2025]

## Overview

Shortcut to Notion is a browser extension that helps you sync story data from Shortcut (formerly Clubhouse) to Notion databases.

## Data Collection

- **No personal data is collected** by this extension
- **No analytics or tracking** is implemented
- **No data is transmitted** to external servers (except Notion API calls)

## Data Storage

- **API credentials** are stored locally in your browser's Chrome storage
- **Configuration data** is stored locally for convenience
- **No data is stored** on external servers

## Data Usage

- **Story data** is only extracted when you explicitly click the extension icon
- **Data is only sent** to Notion API for syncing to your own databases
- **No background monitoring** or data collection occurs

## Permissions Required

- **Host permissions:** Access to Shortcut websites to extract story data
- **Scripting:** Execute scripts to read story information from web pages
- **Storage:** Store your Notion API credentials locally
- **Tabs:** Access current tab to identify which story page you're viewing

## Third-Party Services

- **Notion API:** Only for syncing your stories to your own databases
- **No other external services** or data sharing

## Data Retention

- **Configuration data** is stored until you uninstall the extension
- **No logs or history** of synced stories is maintained
- **Chrome storage** is automatically cleared upon extension removal
